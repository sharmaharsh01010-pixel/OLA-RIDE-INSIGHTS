# OLA Ride Insights 🚗

## Project Overview
Analysis of OLA ride-sharing data to extract business insights using Python, SQL, Power BI, and Streamlit.

## Tech Stack
- Python (Pandas, Matplotlib, Seaborn)
- SQL (SQLite)
- Power BI
- Streamlit

## Project Structure
- `OLA_DataSet.xlsx` - Original dataset
- `OLA_Cleaned.csv` - Cleaned dataset
- `OLA_Cleaned.ipynb` - Jupyter Notebook (EDA + SQL)
- `OLA.pbix` - Power BI Dashboard
- `app.py` - Streamlit Web Application

## Features
- 10 SQL Queries for business insights
- Interactive Power BI Dashboard (5 pages)
- Streamlit Web App with 5 sections

## How to Run
```bash
streamlit run app.py
